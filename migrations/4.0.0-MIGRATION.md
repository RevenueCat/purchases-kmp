# 4.0.0 Migration Guide

This version updates the Android SDK dependency from v10 to v11, which uses Google Play Billing Library 9.1.0, and updates Arrow in `purchases-kmp-either` to 2.x. The iOS SDK dependency does not change major version. See the [Android Native - V11 API Migration Guide](https://github.com/RevenueCat/purchases-android/blob/main/migrations/v11-MIGRATION.md) for a more thorough explanation of the Android changes.

## Android compileSdk 35 or higher
Your Android app, and any module that depends on the SDK, must compile against API 35 or later. Lower values fail with:

```
Dependency 'androidx.core:core:1.15.0' requires libraries and applications that
depend on it to compile against version 35 or later of the Android APIs.
```

If you use `purchases-kmp-either`, the floor is API 36 (see below).

## Jetpack Compose
`purchases-kmp-ui` raises the Jetpack Compose libraries in your Android app to BOM 2026.06.01. See the [Android guide](https://github.com/RevenueCat/purchases-android/blob/main/migrations/v11-MIGRATION.md#jetpack-compose-revenuecatui).

## Blocked Play Store reports `PurchaseNotAllowedError`
When the Play Store is blocked on the device (for example in OEM kids modes), purchases now fail with `PurchasesErrorCode.PurchaseNotAllowedError` instead of `PurchasesErrorCode.StoreProblemError`. `StoreProblemError` is still reported for other store failures, so handle the new code alongside it rather than replacing it.

## Other Play Billing libraries in your app
The Android SDK puts Play Billing Library 9.1.0 on your app's classpath. Any other in-app purchase plugin in the same app, for example one you use to complete purchases with your own code, must support Play Billing Library 9. Versions that use APIs it removed, such as `SkuDetails`, fail at build time or at runtime.

## Arrow 2 in `purchases-kmp-either`
`purchases-kmp-either` now depends on `io.arrow-kt:arrow-core` 2.2.2.1, up from 1.2.4, and exposes it in its API. `Either`, `left()` and `right()` keep their packages, but Arrow 2 removed the APIs deprecated in Arrow 1.x. If your code uses them, follow [Arrow's 2.0 migration guide](https://arrow-kt.io/learn/quickstart/migration/).

Arrow 2.2.2.1 requires Android apps to compile against API 36 or later:

```kotlin
android {
    compileSdk = 36
}
```
