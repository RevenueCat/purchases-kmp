# 4.0.0 Migration Guide

## Error codes

`PurchasesErrorCode.code` now uses the same number for the same error on every RevenueCat SDK, including `purchases-ios` and `purchases-android`. Four values change:

| Error | 3.x | 4.0 |
|---|---|---|
| `PurchasesErrorCode.CustomerInfoError` | 28 | 29 |
| `PurchasesErrorCode.ProductDiscountMissingSubscriptionGroupIdentifierError` | 29 | 28 |
| `PurchasesErrorCode.SignatureVerificationError` | 36 | 37 |
| `PurchasesErrorCode.FeatureNotAvailableInCustomEntitlementsComputationMode` | 37 | 36 |

The enum constants are unchanged, so code comparing against `PurchasesErrorCode.CustomerInfoError` keeps working. Code that compares against, logs or persists the integer must be updated; the compiler does not flag this.

Members are declared in code order, so the two swapped pairs also swap their `ordinal` values. Do not persist or compare `ordinal`; use `code` or the constant itself.
